每张考卷都会被考穿，新卷越来越像真实工作

给模型出的考卷，就是一套大家公认、它没见过的题，加一套固定的判分规则，好让不同模型放在一起比。下面一张大表，按时间列出从 2003 年到 2026 年主要的考卷：考什么、题长什么样、怎么判分、谁考到了多少分、现在还有没有人在用。读的时候留意灰底的横条：每一条都在说，上一代卷子哪里不够用，所以出了下一类。表后一节讲怎么读发布页上的跑分表，想深入的图解放在最后的附录里。

怎么读这一页
  • 主体是一张大表，按时间从上到下；灰底的横条是「时代」分隔，每条写一句：上一代的卷哪里不够用，所以换了这一类。

怎么读这张表

先看规律，再看数字。下面标「我补充的」的，是整理时的归纳，不是某篇资料原话。

三个老问题，从最早一直延续到今天

  • 饱和：分数到顶，再也分不出高低。GLUE 一年多就超过了人类基线，MMLU、GSM8K、HumanEval、GPQA 相继退场；AI Index 2026 说考卷的「保质期」从几年缩到几个月 [23]。每一次饱和之后，就是表里的一条灰底横条：换一类卷。
  • 污染：题或答案进了训练数据，测的是记忆。GPT-2 论文用 8-gram 检查，GPT-3 论文用 13-gram 精确匹配加「干净子集」对比；SWE-bench Verified 后来因污染被 OpenAI 弃用 [24]。新卷靠新题、私有题、保留题来防（做法见附录 C）。
  • 刷榜（古德哈特定律：一个指标成了目标，就不再是好指标）：大家专门冲这张卷，分数和真实能力脱钩。InstructGPT 论文早就指出：公开数据集偏向容易自动评分的任务，在真实用户提示词里只占小头。

题本身有错，是饱和的隐蔽形式。MMLU-Redux 估计 MMLU 约 6.5% 的题有错 [29]，Epoch 估计 GPQA Diamond 约 8% 的题无效 [27]。分数接近「题目的上限」时，100% 不一定意味着全会，也可能只是把错题也「答对」了（图 12，附录 G）。

五个细节：同名的两个分数常常不能比

比较两个分数前，先确认：版本（Terminal-Bench 2.0 与 4.0 任务不同，SWE-bench 有原版、Verified、Pro）、工具（HLE 不带工具与带工具）、脚手架和努力程度、尝试次数（pass@1、pass@k、pass^k）、谁跑的（厂商自报与独立评测可差好几个点，如 DeepSeek-V4-Pro 自报 80.6、CAISI 测得 74.0，二手）。逐条的例子见图 13（附录 G）。

pass@k 和 pass^k：方向相反

pass@k 问「k 次里至少一次对」，衡量模型会不会，是上限；pass^k 问「k 次全都对」，衡量靠不靠得住。同一个模型，pass@10 可以接近 1，pass^10 却只有 0.35（我补充的推算：单次 0.9 的 10 次方）。把「能碰上」当成「能交给它办」，是读智能体成绩最常见的误会（对照见附录 D）。

分数和体验为什么会脱节

  • 能力是锯齿状的：AI Index 2026 说模型能解奥数题，却读不好模拟时钟（ClockBench：模型最高 50.6%，人类 90.1%）[23]。一个总分盖不住这种不均匀。
  • 前沿模型之间已经很接近：差距落在误差范围里时，排名先后不代表体验差别（我补充的）。
  • 考试测的是它设计时想测的东西：真正要用模型做一件事时，最可靠的考试是用自己的任务出一小套题（我补充的）。

我的读法建议（我补充的）：把一个分数当成「某场考试在某种考法下的成绩」，而不是「智商」。读之前先问：这是哪一场考试、哪种考法、谁跑的。

C · 考法与污染：零样本、少样本，以及「考前见过题」（图 4–5）

GPT-2、GPT-3 不再微调，直接问；于是「怎么问」本身成了变量。训练集大到可能装下考卷，所以每张新卷都要先查污染。

GPT-2 论文（2019）：8-gram + Bloom 过滤器。把 WebText 训练集所有的 8-gram（连续 8 个词的片段；原文先把字符串归一化成「全部小写、只留字母数字、单词间单个空格」）装进一个 Bloom 过滤器，再拿测试集的每个 8-gram 去查。Bloom 过滤器是一种节省空间的集合：它能回答「这个元素可能在集合里 / 一定不在」，允许有少量「误报」（说在其实不在），但不会漏报。作者把误报率上界设在 1/108，并生成 100 万个随机字符串验证，查到 0 个。

读法：「测试集中有多大比例的 8-gram 也出现在训练集里」。这是召回优先的检测（宁可多报），所以数字里包括很多「常见短语」，不全是真泄漏。结论是记忆带来小而稳定的好处，不是主因。

GPT-3 论文（2020）：13-gram 精确匹配 + 干净子集。

  1. 对每个基准，取一个窗口长度 N（该基准样本长度的第 5 百分位词数，最小 8，最大 13）。
  2. 在整个训练集上做精确匹配：测试样本里的任一 N-gram 若出现在训练文本中，就把这个样本标为 dirty，否则为 clean。
  3. 把模型在 clean 子集上的成绩与全集成绩对比。如果 clean 成绩明显更低（超过 1–2%），说明模型可能靠见过的样本占了便宜；如果 clean 反而明显更高，说明过滤把「容易的题」优先标成了 dirty。

小数字例子（构造）：测试句有 15 个词 w1…w15。13-gram 共 15−13+1 = 3 个（w1–w13、w2–w14、w3–w15）。只要这 3 个中有任何一个出现在训练文本里，该句就被标为 dirty。如果一个基准 1000 题，其中 200 题 dirty，模型在全集上 70%、在 clean 800 题上 69%，则差 1 个百分点，污染影响小；如果 clean 上只有 62%，则怀疑模型从污染中获益。

作者承认的局限：clean 子集与全集的难度分布未必相同；N-gram 检测会对「含背景知识的数据集」（如 SQuAD 来自 Wikipedia）产生大量假阳性，因为源文本被见过不等于问答对被见过。重训修正在经济上不可行，所以加星号的结果要保守看待。

对比：GPT-3 论文的检查比 GPT-2 论文严格得多，精确匹配、窗口更长（13 对 8）、逐任务报告。Chinchilla 论文没有逐题检测，只是主动提醒，并更看重泄漏风险较小的 MMLU、BIG-bench。

D · 题与判分的换法：MMLU、HumanEval、pass@k（图 6–8）

MMLU 改的是题：从语言技能转到知识和推理。HumanEval 改的是判分：BLEU 一类的文字重合，对代码失灵，改成真的跑单元测试。同一个功能有无数种写法：文字不像的程序可能完全正确，文字很像的程序可能差一个符号就全错；Codex 论文的 Fig 8 把正确样本和错误样本的 BLEU 分布画出来，大量重叠。

同一个模型，在三道题上的单次成功率可以差两个数量级以上。重复采样把一个低但非零的成功率放大成高成功率。反过来，对同样的 p = 0.9，pass^10 是 0.9 的 10 次方，约 0.35（推算，我补充的），远低于 pass@10 的 ≈ 1.0。这就是「会不会」和「靠不靠得住」的差别。

E · 没有标准答案时，让人来判（图 9）

写邮件、解释概念、陪人聊天，没有唯一的正确答案，既跑不了测试，也算不了 BLEU。换掉的零件是判分：交给人，用「两个回答选一个」换算成 Elo。人评贴近真实使用，但贵、慢、难复现，而且评委有口味（我补充的）；InstructGPT 论文指出了一个循环：评委的口味恰好就是奖励模型学的那份口味。

FrontierMath：未发表的原创研究级数学题，与 60 多位数学家共同出；答案是可机器核对的数值或表达式；典型题要研究者数小时。另一道官方样题：Artin 原根常数，「Compute ⌊10^6 d_∞⌋」（答案 367707）。Tier 4：OpenAI 自报 GPT-6 Astra 97.6%（Epoch 本人未确认）。Erdős 新版 68 题，GPT-6 Astra 解出 2 题（Epoch 页面，截至 2026-09-03）。Tier 1–3 仍在用；Epoch 已推出用开放问题、Erdős 问题出题的新版本接续 [26]。

Humanity's Last Exam（HLE）：各学科专家出题，覆盖数学、人文、自然科学；设私有保留集。均为厂商自报，各家判分口径不同：Gemini 3 Pro（2025-11）37.5% 不带工具 / 45.8% 带工具；Kimi K3（2026-07）43.5 / 56.0；Claude Opus 5.5（2026-09）带工具 67.7。AI Index 2026：头部模型一年涨了约 30 个百分点。lastexam.ai 页面称 HLE 已于 2026-01-28 发表在 Nature（649, 1139–1146），并有滚动更新版 HLE-Rolling（2025-10-08）和 HLE-Diamond（2026-09-22）（依据搜索结果，未逐一核对）。样题的英文原文是网上广泛转引的版本，论文 Fig 2 是图片，我没能在文本里核对。

AIME / HMMT 与 MathArena：MathArena 只用模型发布之后才出现的新竞赛题。论文：AIME 2024 上有明显的污染迹象；顶级模型 IMO 2025 题不到 40%、USAMO 2025 不到 25%。前沿模型在 AIME / HMMT 上 95–99%（整理站 BenchLM，二手，待核实）。Gemini 3 Pro 自报 MathArena Apex 23.4%。竞赛题已被刷满，转向 MathArena Apex、FrontierMath 这类更难的。

ARC-AGI 系列：对人容易、对模型难；ARC-AGI-3 改成交互式小游戏。ARC-AGI-2：Gemini 3 Pro 31.1%（2025-11，自报），Gemini 3.1 Pro 77.1%（2026-02，二手）。之后 ARC-AGI-3 的自报分数差异极大（二手转述：GPT-6 Astra 99.9%，Opus 5 30.2%），待核实，以 ARC Prize 官方榜为准。

SWE-bench（原版）：给代码库和问题描述，让模型改代码；指标是解决率。后来有人工验证的 Verified 子集和更难的 Pro 两个版本。

OSWorld（Verified → 2.0）：真实操作系统的虚拟机里完成跨应用的开放式任务。AI Index 2026：从约 12% 到 2025 年的 66.3%，人类基线 72.35%。GPT-5.5 在 OSWorld-Verified 78.7%、Opus 4.7 78.0%（OpenAI 发布页，二手转述）。OSWorld 2.0（2026，108 个长任务）：论文称最佳模型二元完成率仅 20.6%；另一篇二手文章称已超过 45%，两者冲突，待核实。

τ-bench（τ²-bench）：模拟用户 + 工具 + 业务规则。pass^k：k 次尝试全部成功的概率。Claude Opus 4.5（2025-11）τ²-bench 零售 88.9、电信 98.2（二手）。厂商几乎只报 pass^1，掩盖了「多次是否都对」。

SWE-bench Verified：AI Index 2026：一年内从约 60% 涨到接近 100%。DeepSeek-V4-Pro 自报 80.6%，美国 CAISI 独立测得 74.0%（二手，待核实）。OpenAI 2026-02 起不再报告：一是污染（GPT-5.2、Opus 4.5、Gemini 3 Flash Preview 能背出部分原始修复），二是测试有缺陷：审查 138 道 o3 没稳定解出的题，至少 59.4% 的测试会拒绝功能正确的提交 [24]（依据搜索摘要，待核实）。仍有厂商在报。

BrowseComp：需要持续上网、拼凑难找信息。Gemini 3.1 Pro 85.9（OpenAI 表）。论文作者请求不要在网上明文公开样题，这里只摘了论文自己列出的一道的开头。

SWE-bench Pro：设保留集和私有商业仓库防污染；跑仓库测试。发布时 GPT-5 与 Opus 4.1 在 SWE-Agent 下不到 25%。GPT-5.5 58.6、Opus 4.7 64.3（OpenAI 发布页）；Qwen3.8-Max 67.7（自报）。HuggingFace 公开测试集我看到 642 行 [42]。

GDPval：美国 GDP 前 9 大行业的 44 个职业，由平均 14 年经验的从业者设计的真实工作任务，要交出文件。同职业专家盲评，和人类专家的作品比。首批结果（2025-10）：Claude Opus 4.1 47.6%，GPT-5 high 38.8%。全集题量另有来源写 1,230，冲突，待核实。公开子集 220 行已在 HuggingFace 核对 [42]。Artificial Analysis 与 Anthropic 报的是自己的 GDPval-AA 变体（Elo 制）。

Terminal-Bench：题目取自 2.0 版的 fix-git。版本在变：2.1 修了 28 个任务；4.0（2026-08-28 宣布）删 8 个、修 19 个、改了任务运行方式，任务数 74 → 66（和 2.0 的 89 个是什么关系，没查清），分数与旧版不可直接比。Claude Opus 4.5 59.3（2025-11）；GPT-5.5 82.7（2.0，2026-04，OpenAI 自报）。4.0：Claude Opus 5.5 66.4（Anthropic 自报）、Gemini 4 Argon 57.4（官方页）。
